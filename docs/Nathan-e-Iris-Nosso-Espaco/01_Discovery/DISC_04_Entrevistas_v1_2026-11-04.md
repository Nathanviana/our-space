# 04 Entrevistas em Profundidade: Nathan & Iris · Nosso Espaço

> **Como ler este documento.** A Parte A é preparada antes do campo e a Parte B é preenchida depois, com base nas transcrições. As **entrevistas de dores** investigam a fundo o problema com quem o vive. As **entrevistas de alinhamento** mostram o que foi encontrado para confirmar ou ajustar. Os entrevistados aparecem por código (E1, E2...) para proteger a identidade. Cada achado indica em quantas entrevistas apareceu e se foi confirmado no alinhamento.

Itens encaminhados pela Matriz CSD (02) e pela seção 8 da Mercado e Concorrentes (03).

## 2. Planejamento

| Tipo | Quantidade | Perfil dos entrevistados | Critérios de recrutamento | Formato |
|---|---|---|---|---|
| Dores | 1 (conversa a dois) | Nathan (E1) e Iris (E2), o casal usuário do produto | Os únicos usuários previstos do produto (C7 da Matriz CSD) | Presencial, os dois juntos, conduzida pelo Claude via chat |
| Alinhamento | A definir após a entrevista de dores | Nathan e Iris | Os mesmos entrevistados | A definir (sugestão: conversa curta via chat) |

**Atenção:** por ser uma conversa a dois, um entrevistado pode concordar com o outro por influência. Nas perguntas marcadas como "(cada um)", cada um responde primeiro a própria história antes de comentar a do outro, para reduzir esse efeito em S3 e R2.

**Consentimento:** no início da entrevista, Nathan e Iris confirmam no chat que concordam com o registro das respostas e com o uso nos documentos do Discovery. A conversa do chat é a transcrição, com cada resposta identificada por quem respondeu.

## 3. Roteiro da entrevista de dores

Perguntas abertas, sem sugerir respostas, ligadas aos objetivos da seção 1. Duração prevista: 40 minutos.

| Fase | Tempo | Perguntas | Código |
|---|---|---|---|
| Apresentação | 2 min | Apresentação do condutor, explicação do formato e confirmação do consentimento | |
| Objetivos do projeto | 2 min | Explicar que a conversa busca entender como o casal guarda planos e lembranças hoje, e que não existe resposta certa | |
| Rapport | 5 min | 1. Contem um pouco de como vocês se conheceram e o que gostam de fazer juntos. 2. Qual foi o último programa de vocês? | |
| Histórias vividas | 15 min | 3. Me contem da última vez que surgiu a vontade de fazer algo juntos, como um lugar ou um filme. O que aconteceu com essa ideia depois? | S1 |
| | | 4. Lembram de algum plano que vocês combinaram e acabou não acontecendo? Como foi? | S1 |
| | | 5. Me contem da última vez que vocês relembraram um momento juntos. O que fizeram e onde estavam as fotos? | S2, D1 / M1 |
| | | 6. Como vocês escolheram o último filme ou série que viram juntos? | Seção 4 (03) |
| | | 7. (cada um) Conte um momento de vocês que você não quer esquecer. Como ele ficou guardado? | S2, S3 |
| Emoções e percepções | 8 min | 8. (cada um) Como você se sente quando um plano de vocês fica esquecido? | S1, S3 |
| | | 9. Como é para vocês olhar fotos antigas juntos? | D1 / M1 |
| | | 10. Tem alguma coisa de vocês que preferem guardar só na memória, sem registrar em lugar nenhum? Por quê? | R4 |
| Perguntas objetivas | 6 min | 11. Além de passeios, viagens, brincadeiras, filmes e séries, o que mais vocês fazem ou querem fazer juntos? | D4 |
| | | 12. (cada um) Hoje, quem costuma guardar as fotos, os links e as ideias de vocês? | R2, S3 |
| | | 13. Pensando em coisas que vocês já tentaram manter, como uma lista, um álbum ou um caderno, o que fez continuar ou parar? | R1 |
| | | 14. Onde ficam hoje os filmes e séries que vocês querem ver ou já viram? | Seção 4 (03) |
| Encerramento | 2 min | Agradecer e perguntar se querem acrescentar algo | |

**Lembretes de condução:** não sugerir respostas; explorar contradições; pesquisa não é venda; cuidado com conclusões apressadas e com as próprias reações; o entrevistado pode responder o que acha que você quer ouvir.

## 4. Roteiro da entrevista de alinhamento

| Momento | Tempo | O que fazer |
|---|---|---|
| Abertura | 2 min | Retomar o objetivo e explicar que a conversa é para conferir o que foi entendido |
| Apresentar o que foi encontrado | 5 min | A preencher com os achados da entrevista de dores, em linguagem simples, sem apresentar soluções |
| Confirmar ou ajustar | 8 min | "Isso faz sentido para vocês?", "O que está diferente da realidade de vocês?" |
| Lacunas | 3 min | A preencher com o que continuar em aberto após a entrevista de dores |
| Encerramento | 2 min | Agradecer |
